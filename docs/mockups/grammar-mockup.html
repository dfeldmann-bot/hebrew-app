The binyan path

The seven binyanim come in active and passive pairs. If you learn them as pairs, each new binyan reuses what you already know.

פָּעַל ↔ נִפְעַלbasic action ↔ passive / happens to you
פִּעֵל ↔ פֻּעַלintensive or "do to" ↔ its passive
הִפְעִיל ↔ הֻפְעַלcause someone to ↔ be caused
הִתְפַּעֵלreflexive / to each other / oneself

The pattern you just saw

מְ □ַ □ֵּ □

Pi'el present, masculine: מְ + root letter 1 with "a" + root letter 2 doubled with "e" + root letter 3. Feminine adds ֶת: מְדַבֶּרֶת.

How to spot it without vowels

Present-tense pi'el usually looks like מ + 3 letters: מדבר, מספר, משלם. Pa'al present has a ו after the first letter instead: כותב, לומד.
